Dokumentasi Hari 2 – Pengujian Query Overpass
1. Tujuan
Melakukan pengujian query menggunakan Overpass Turbo untuk menentukan batas wilayah Kecamatan Kintamani dan mencari lokasi akomodasi berdasarkan data OpenStreetMap.
2. Sumber Data dan Tools
•	Sumber data: OpenStreetMap (OSM).
•	Tools: Overpass Turbo.
•	Wilayah penelitian: Kecamatan Kintamani, Kabupaten Bangli, Bali.
3. Batas Wilayah
Pencarian wilayah menggunakan tag administratif:
•	name: Kintamani
•	boundary: administrative
•	admin_level: 6
4. Jenis Akomodasi
Jenis akomodasi yang dicari meliputi:
•	Hotel
•	Guest House
•	Hostel
•	Motel
•	Apartment
•	Chalet
5. Hasil Pengujian Query
Query berhasil dijalankan pada Overpass Turbo dan menampilkan objek akomodasi pada peta wilayah Kintamani.
Berdasarkan hasil pengujian:
•	Nodes: 31
•	Ways: 1
•	Relations: 0
•	Total elemen: 32
Jumlah tersebut merupakan elemen hasil query dan belum seluruhnya diverifikasi sebagai penginapan unik atau aktif.
6. Dokumentasi Hasil
Bukti pengujian disimpan dalam file:
•	query_overpass.txt
•	bukti_peta_hari2.png
7. Kesimpulan
Pengujian query menggunakan Overpass Turbo berhasil dilakukan untuk menentukan wilayah pencarian dan mengidentifikasi objek akomodasi di Kecamatan Kintamani. Hasil pencarian akan digunakan sebagai dasar untuk proses akuisisi dan pemeriksaan data pada tahap berikutnya.
8. Sumber
•	OpenStreetMap: https://www.openstreetmap.org/
•	Overpass Turbo: https://overpass-turbo.eu/
