 Tujuan
    Melakukan pengujian kelengkapan (completeness) data akomodasi yang telah diperoleh dari OpenStreetMap (OSM).
Perbandingan Jumlah Data
    Jumlah data akomodasi yang diperoleh dari OSM adalah 34 data.
Berdasarkan data BPS Kecamatan Kintamani Dalam Angka 2024 (data tahun 2023), terdapat 19 hotel dan 99 penginapan, sehingga total pembanding adalah 118.
Perbandingan jumlah data OSM terhadap data BPS:
    34 / 118 × 100% = 28,81%
Angka tersebut merupakan rasio perbandingan jumlah data, bukan persentase akurasi 
atau kelengkapan yang pasti karena sumber, tahun, dan kategori data dapat berbeda
Verifikasi Sampel
    Dilakukan pemilihan 10 sampel data secara acak untuk diperiksa secara manual.
Aspek yang diperiksa:
-Kesesuaian nama akomodasi.
-Kesesuaian jenis akomodasi.
-Kesesuaian lokasi.
-Hasil pemeriksaan dicatat pada file verifikasi_10_sampel.csv.
File Hasil
  -verifikasi_10_sampel.csv: hasil pencatatan verifikasi sampel.
